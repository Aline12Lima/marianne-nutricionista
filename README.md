# 🥗 SPA – Nutricionista Marianne

Uma **Single Page Application (SPA)** desenvolvida com **React + TypeScript + TailwindCSS + Vite** para apresentar de forma profissional os **serviços de divulgação de uma nutricionista**, com foco em usabilidade, responsividade e apresentação clara das informações.

## Sobre o Projeto

Este site foi criado para uma nutricionista divulgar seus **serviços profissionais**, **sobre ela**, **contatos**, e possibilidades de **agendamento ou comunicação com pacientes**. A SPA é leve, moderna e pode ser facilmente **personalizada ou expandida com novas seções ou rotas**.

## Funcionalidades

✔ Landing page com informações da profissional  
✔ Seções para:  
- Quem é a nutricionista  
- Serviços e especializações  
- Depoimentos / resultados (se aplicável)  
- Formas de contato  
✔ Responsivo para mobile e desktop  
✔ Navegação fluida sem recarregar a página

## Tecnologias utilizadas

- **React** – biblioteca principal para a UI  
- **TypeScript** – tipagem estática e mais segurança no código  
- **Vite** – bundler rápido para desenvolvimento  
- **TailwindCSS** – estilos utilitários  
- **Git & GitHub** – versionamento e hospedagem do código  
- ⚡ Possível uso de Hooks e componentes funcionais
